# Journey - Personal Journaling App

A beautiful and modern journaling application built with HTML, CSS, and JavaScript.

## 🎨 Frontend Structure

### Pages
- **index.html** - Landing page with features and hero section
- **signin.html** - Sign in page
- **signup.html** - Sign up page  
- **dashboard.html** - Main dashboard/journal app

### Files
- **styles.css** - Complete styling for all pages
- **app.js** - Frontend JavaScript for navigation and interactions

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Navigate through the pages using the navigation buttons
3. All frontend functionality is working (navigation, forms, dashboard interactions)

## 🔗 Navigation Flow

1. **Home (index.html)** → Click "Sign In" or "Get Started"
2. **Sign In/Sign Up** → Submit form → Dashboard
3. **Dashboard** → Create journals, entries, and manage content
4. **Dashboard** → Logout → Home
